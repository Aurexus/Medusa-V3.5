Instructions to add new Unique Project Identification Number (UPID)

The syntax for UPID is
<YEAR OF PROJECT START>.<PROJECT NUMBER>.<LOCATION>.<SUB PROJECT NUMBER>

Eg: 2024.20.P.1

<YEAR OF PROJECT START> - The year in which the project is started.
Syntax - <YYYY> e.g.: 2024, 2023 etc

<PROJECT NUMBER> - The project number for the year. Like 1st / 2nd / 3rd .. project of the year for the company.
Syntax - <NN> e.g.: 01,02,03…..10,22 etc..

<LOCATION> - The location where the project is executed. Like PONDY / FRANCE / MADA / MAU
Syntax - <X> e.g.: P / F / M / W

<SUB PROJECT NUMBER> - The sub project number is number / lot / batch of the respective project. By default when a project is created the sub project number is 1. And it gets incremented based on the batch / lot etc.
Syntax - <X> e.g: 1 / 2 / 3 etc.

Various examples:
2024.20.P.1
2024.01.F.1
2024.01.M.2
2024.20.P.2
2023.2.P.10
